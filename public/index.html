How it works

Built on infrastructure your security team already trusts.

No new database, no new identity provider. Postgres, OAuth, audited tool calls, full row-level isolation.

Tenant-isolated by default

Every agent runs inside Postgres Row-Level Security. Your data never touches another customer's data — enforced inside the database, not your app code.

Every action audited

Every tool call goes through an append-only audit log. Replay any agent's session, prove what happened, satisfy SOC 2 and GDPR controls without writing custom logging.

Humans on the loop, not in it

Agents draft. Humans approve high-stakes actions: contracts, refunds, merges, public posts. Configure per-action policy in plain English.

Brings its own integrations

Stripe, HubSpot, Linear, Slack, Notion, GitHub, Gmail, Zendesk, Twilio. Bring credentials once — the right agent picks the right tool.

Replayable bus

Every inter-agent handoff is a row in Postgres. Reproduce any state by replaying the bus — same as event sourcing, no Kafka required.

Self-host or managed

Deploy to your own Supabase + n8n in 60 minutes, or stay on our managed plane. Same code, same data model.

FAQ

Things people usually ask first.

Which LLM powers each agent?
Vikram, Arya, Lakshmi, and Riya run on Claude Sonnet 4.6. Priya runs on Claude Haiku 4.5 for low-latency support replies. Dev runs on Claude Opus 4.6 for engineering work. You can override per-agent in admin → Models.
How do you stop one tenant's data from leaking into another's?
Postgres Row-Level Security with FILTER + BLOCK predicates on every tenant-scoped table. Even if our app server is compromised, the database refuses to return cross-tenant rows. Independent pen-tested, full report on request.
Can I bring my own Anthropic key?
Yes, on Growth and Enterprise. Drop your key into Settings → Models. Your traffic never hits our LLM accounts. Useful for billing attribution or your own model commitments.
What happens when an agent makes a mistake?
Every agent action goes through an append-only audit table. You can roll back any state-changing operation, replay the conversation, and adjust the policy that allowed it. We treat agent errors as a debuggable system, not a black box.
Is there a free tier?
14-day free trial of Growth — no credit card. After trial, drop to Starter or upgrade to Growth. We don't downgrade you silently or hold features hostage.
How fast is deployment?
Connect Stripe + Slack + email + your CRM, set per-agent policies, you're live the same day. Most customers ship to staging in under 60 minutes; production within a week including security review.
